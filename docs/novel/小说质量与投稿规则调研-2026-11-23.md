# 小说质量与投稿规则调研

核对日期：2026-11-23。目标平台：番茄、起点／阅文、晋江。本文区分官方可核对的材料、材料的适用范围，以及 MoJing 的工程改进；没有把论坛经验当成平台规则。

## “过审”不是一个指标

1. **内容发布审核**：内容与平台发布规范、原创及版权要求是否相符。
2. **签约评估**：编辑是否认可选题、人物、情节与后续连载价值。能发布不等于能签约。
3. **读者阅读效果**：是否愿意继续阅读、人物是否可信、承诺是否兑现。签约与商业成绩也不是同一件事。
4. **AI 内容相关规定**：具体平台、具体产品和合同对生成内容、辅助创作、声明的要求，须分别核对，不能推导成“三个平台都禁AI”或“改几个词就能通过”。

## 把小说写好，需要检查什么

以下是创作与编辑工作的判断框架，不是平台硬性规定，也不要求每一章机械满足一张表。

- **作品承诺**：题材、主角处境和独特看点是否明确；简介吸引来的读者，正文是否真的得到相应体验。
- **人物能动性**：人物想要什么，为什么现在必须行动；阻力是否涉及真实利益，选择是否会失去东西。配角有自己的目的，不只是发线索或衬托主角。
- **因果与情节变化**：事件的后果迫使人物调整下一步。连续几章只换地点问人、查记录，调查再多也不等于故事发生变化。
- **关系与人物弧线**：冲突、合作和信任由具体行动积累，转变要有过程；不能靠性格标签、口头禅、突然悔悟解释一切。
- **悬念与兑现**：先想清原始异常的真实原因，再安排人物怎样发现；线索有来源与可见范围，结局依靠此前铺垫，而非临时增加证人、道具或更大的阴谋。
- **长篇连续性**：日期、年龄、空间、伤势、物品数量与归属、谁知道什么、已经作出的约定必须承接。作者规划不能直接变成人物已经知道的事实。
- **节奏与场景价值**：重要选择应充分发生；没有变化的准备、路程和转述可以省略。安静场景也可改变关系和认识，不必每章硬造反转。
- **语言与视角**：声音服务于人物和场景。削减重复意象、空泛解释与雷同对话，保留必要心理和直接说明；不以“每段一个微表情”“禁止所有某类词”为文笔标准。
- **现实细节与原创性**：不能把编造的医疗、职业或法律流程写成行业常识；不模仿具体作品换名重写。独特性来自具体处境、人物关系和选择，不只来自冷僻词。
- **修订效果**：先修会影响后续故事的结构与因果，再润色语言。建议必须确有阅读收益，修改后仍要通读，防止为了修一个漏洞制造另一个。

## MoJing 本轮落实的改进

1. 先审读完整情节方案，再进入正文；创建向导与自动规划都走这一步。检查原始谜题、人物动机、时间道具、重复推进和结局因果。存在未解决问题时不把新方案当作可写方案采用。
2. 作者原始设定、已写正文与AI推演分开使用。世界观生成不再要求心理配额、微表情配额或普通词语禁用表，也不得把“没有证件”等观察直接写成唯一动机。
3. 截断时只提高输出预算重试一次，不重做已完成的世界观、人物和地点，不拼接不完整JSON。账户、限流和网络错误不因此自动重复计费请求。
4. 兼容自定义接口中的DeepSeek V4及V4.1思考模式；单章规划、全局规划和写前审稿的输出额度也做对应处理。
5. 在“剧情 → 全书情节”显示已保存的主线、阶段关键事件、铺垫和结局，并兼容旧项目的简要总纲及自动规划资料；作者可以对照正文检查实际方案。

自动审读仍可能漏报或误报。验证必须分别记录“请求完成”“数据保存与使用正确”“编辑意见是否成立”“正文是否好读”，不能把程序测试通过写成文学质量认证。
