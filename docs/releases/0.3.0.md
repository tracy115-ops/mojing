# MoJing 0.3.0

视频工坊与世界引擎更新，2026-11-16。

## 安装与使用

Windows x64 安装包为 `MoJing_0.3.0_x64-setup.exe`。安装前关闭旧版本，已有项目请先导出备份。应用继续使用既有本地数据目录；本包不含用户项目、模型密钥和上传存储凭证。

安装后从顶部「视频工坊」进入新创作空间。原项目继续使用短剧项目中的制作流程。Agnes、Seedance 等模型需在设置中配置有权限的接口与账号；本地 MP4、逐帧导出和视频合成需要可用的 FFmpeg／FFprobe。

## 本次变化

- 重做视频创作空间，提供创作首页、短剧项目、无限画布、世界引擎、图像工作台、视频工作台、电商创作、素材库、任务与记录、创作技能及模型与插件入口。
- 完善逐镜规划、角色／场景／构图参考、质量检查、候选审核、连续性、时间线与成片失效处理。
- 完善 Agnes 和 Seedance 的原生参数、首尾帧、主体参考及音视频参考约束；结果记录采用实际响应或本次提交的档位。
- 新增画布局部图像编辑、画笔蒙版、素材包、文件夹／标签／回收站，以及分镜素材回流。
- 新增 S3 兼容参考媒体上传、临时链接续期、失败恢复和上传任务管理。
- 世界引擎支持场景与 GLB、人物走位和姿态、多机位序列、双／四画面监看、GLB 动作片段与速度，以及固定时间逐帧 H.264 MP4 预演导出。
- 随安装包提供第三方版权说明。

## 已知边界

小云雀专用接口尚未接入，需要真实开放 API；Seedance 成功生成和画质仍需真实账号联调。模型画质取决于实际模型，Agnes 免费 Flash 的原生尺寸限制仍适用。

世界引擎用于场景预演；逐帧导出为最长 60 秒的无声视频，支持 1280／1920 长边和 15／24／25／30 fps，不包含物理写实渲染。逐帧任务暂不支持重启续导或异常退出后的自动缓存回收。

多动作混合、IK、骨骼重定向、方舟私有资产注册，以及服务端技能／插件运行时、云协作等仍待实现。当前创作技能支持方法管理和提示应用。

逐项迁移范围、验证记录和更多限制见 [视频模块文档](../video-generation/README.md)。

## 发布验证

Windows x64 NSIS 安装包已构建。28 组契约测试和 4 项 Rust 原生测试通过；视频工坊页面及制作流程此前已完成隔离浏览器回归。

发布版程序使用独立 WebView2 数据目录完成真实桌面验证：真实 IPC 调用逐帧生成和编码 24 帧、1280×720、24 fps 的 H.264 MP4，核对成片后保存到素材库，播放实际磁盘文件并在页面重新加载后恢复。该验证没有调用生成模型，未消耗模型额度。
