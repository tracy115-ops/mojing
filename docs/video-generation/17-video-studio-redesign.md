# 视频创作工作区：页面审计、设计与迁移覆盖

核对日期：2026-11-16。上游为 [ddcat-ai/open-ai-canvas](https://github.com/ddcat-ai/open-ai-canvas)，固定版本
[`a0bdc23f450262e3a00e94019ed703fa42ba5e60`](https://github.com/ddcat-ai/open-ai-canvas/tree/a0bdc23f450262e3a00e94019ed703fa42ba5e60)。
本报告基于路由、页面组件、世界引擎、生产与 Provider 源码审查；没有启动上游云端服务，也没有逐页登录其线上后台。

本轮已接通本地创作主流程，覆盖 11 个入口。**这不是上游全部功能的完整移植。**
下表把已可操作的本地功能、保留的现有功能、部分覆盖及尚需服务端的能力分别写明。

## 设计与依赖选择

视频工坊入口改为 `StudioWorkspace`，创作空间由三个工作区和共用资源组成：

| 工作区 | 制作目的 | 主要布局 |
| --- | --- | --- |
| 短剧项目 | 剧本、角色与场景设定、逐镜制作、版本审核、时间线成片 | 复用现有项目导航、制作阶段、分镜表／画面墙、单镜工作台和时间线 |
| 无限画布 | 自由组织创意、文本、参考和生成依赖 | 顶部文档与批量操作、中央节点画布、右侧节点参数、缩略导航 |
| 世界引擎 | 摆场、演员走位、机位与动画预演 | 左对象树、中央 Three.js 视口、右属性检查器、底部时间线 |
| 图像／视频／电商工作台 | 单项生成与营销画面制作 | 输入、参考及模型参数与结果同屏；电商采用商品简报与制作区双栏 |
| 素材、任务、技能、模型与插件 | 共用资产、执行记录和可复用配置 | 检索工具栏、卡片或表格、详情与编辑弹窗 |

统一左侧导航分为创作、工作台和资源三组。窄窗口收起文字导航；世界引擎在 900px 下把属性区放到视口下方，
画布仍可平移与缩放。所有新增业务样式放在 `VideoStudio` 内，使用已有主题变量和中英文文案。

保留 Tauri、React 19.1、Ant Design 5、Vite 6、Zustand 与现有 Provider／FFmpeg 架构。
上游使用 React 19.2、Ant Design 6、Vite 8，以及 React Three Fiber、tldraw、Excalidraw、Tiptap、服务端插件和 Go API 等依赖。
不要求整个应用随其升级：本次在现有组件体系内重写画布、世界引擎和工作台，只新增 `three` 与 `@types/three` 0.187。
这是一项兼容性选择，不代表已经证明上游所有依赖都无法安装。

## 世界引擎功能与边界

对应上游 `types/previs.ts`、`components/canvas/previs/` 和 `lib/canvas/previs/`，本地实现位于
`WorldEngine.tsx`、`world-renderer.ts`、`world-animation.ts` 与 `document.ts`。

| 能力 | 已可操作 | 尚未迁入 |
| --- | --- | --- |
| 场景搭建 | 城镇集市／喷泉庭院完整离线布景、14 类内置纹理 GLB 道具、查看全景；空场、双人对话、街景模板；演员、方体、球、圆柱、树、建筑、GLB；变换、颜色、可见性、复制／删除 | 完整在线道具／地形／图片立牌库、物理与碰撞、复杂对象层级；竞品截图的城市资产未公开，未直接迁入 |
| 人物表演 | 10 个关节、站／坐／蹲／伸手／指向／展臂姿态、姿态关键帧、走跑与招手 | 上游完整动作片段库、体型原型、手指骨骼、IK、外部角色骨骼映射与重定向 |
| 模型动画 | 读取 GLB 内嵌动画目录、选择动作和源区间、0.1–4 倍速、延迟入场、循环或末帧保持、时间线动作条；与播放／倒拖、切镜和预演导出同步 | 多动作拼接、分层混合、重定向与骨骼轨道编辑；依赖外部 Draco／KTX 解码器的压缩模型尚未配套 |
| 走位 | A→B 行走、B→A 跑步、鼠标地面轨迹，按路径距离分配关键帧；演员与机位可使用 | 上游完整导航、地面吸附修复与场景重建 |
| 摄影 | 自由视角／摄影机、焦距／目标／画幅、当前视角对齐、推进／拉远／平移／环绕／升起、机位书签；独立快照的多机位切镜序列、排序／复制／时长／运镜、连续动画预演与导出；双／四画面同步监看、单机位参考图与完整运镜采用 | 淡化／叠化、完整景别与抖动／摇镜预设、多路独立录像与拼屏导出 |
| 时间线 | 对象与摄影机关键帧、姿态插值、时间缩放、记录／删除、播放／暂停／回头 | 骨骼轨道剪辑界面、分层动作、音频调度和完整缓动曲线编辑 |
| 输出 | 材质、白模、线性深度；长边 1280 的 PNG／固定时间逐帧 WebM；桌面 1280／1920 长边固定时间逐帧 H.264 MP4、原生编码核对、取消与重试编码；素材库与画布回用、工程含媒体导入导出 | 法线／OpenPose 通道、物理写实渲染、音频同步、多路独立录像与拼屏导出 |
| AI 导演 | 已配置 LLM 输出完整可校验方案，审阅后应用，可撤销；不存在“应用方案即自动花费生图额度” | 图像到 3D 场景恢复、常驻 Agent 工具循环与完整预演提示编译器 |

应用到分镜时，将预演图作为“构图和机位参考”，角色身份仍使用真实角色图。
该操作替换镜头手工参考，并将衔接设为切镜；弹窗有明确说明。旧关键帧与视频按输入变化失效，随后重新制作。
实际模拟请求已验证角色图与预演图同时进入关键帧请求，不会只保存一个界面标签。
多机位可在预览构图后逐项映射既有分镜，一次更新全部参考与产物失效；场景或项目已变化及制作中状态会拒绝回流。详见 [20-world-camera-sequence.md](./20-world-camera-sequence.md)。

## 生成、保存与模型扩展

- 单项、画布及电商都通过现有 Provider Router 发请求，按模型能力约束参考语义、尺寸、时长和分辨率。
- 提交时固定接口、模型与创作方法提示，后续修改默认渠道或模板不会改写排队请求。
- 画布按依赖顺序生成；停止批次会阻止后续提交，已在运行的远端任务继续产生可查结果。
- 重启后的未完成任务标为需要恢复，不自动重新提交。取消尚未运行的任务不会调用 Provider。
- 模型已生成成功而本地下载失败时，保留结果链接并标出保存失败，避免把下载失败伪装成生成为失败而重复付费。
- 桌面媒体存盘，浏览器媒体嵌入 IndexedDB；导出画布／世界会包含引用媒体与模型。导入先整包校验，再为资源及文档分配新 ID。
- 接口分享配置不导出 API Key 或自定义鉴权头；含账户／查询参数的接口地址拒绝分享导出。导入接口默认禁用且密钥为空。

Agnes 免费 Video 2.5 Flash 仍为原生 720P，16:9 为 **1280×704**、时长 4–12 整数秒、最多 5 张图片／3 段音频，不支持视频参考。
角色、场景和分镜关键帧默认至少 2K，可选原生 1K–4K。提高输入质量与修正镜头提示不会自动突破视频模型的原生上限。

Seedance 2.0／2.5 的既有 `doubao-video` 适配器已完善首尾帧、主体参考、seed、时长和分辨率约束；
账号具备权限后可在模型设置中配置并绑定。详见 [15-doubao-seedance.md](./15-doubao-seedance.md)。
小云雀需依据其实际开放 API 增加适配，不能仅凭产品名当作 Seedance 兼容接口。本轮没有小云雀账号或专用 API 配置。
