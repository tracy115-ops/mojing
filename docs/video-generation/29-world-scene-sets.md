# 世界引擎：完整场景与图片背景

完整场景不是一张导入图片，而是已布置好的立体场景。每幢建筑、树木、摊位和角色都能独立变换、隐藏、复制和删除；换机位会产生真实的视差、遮挡和阴影，也能输出白模／深度作为生图参考。

竞品 README 的世界引擎标为内测。本次核对公开主干完整文件树与 previs 模块，未找到 README 古代城市截图对应的场景资产。不能把编辑器源码或一张截图当作已获得完整城市。MoJing 使用明确许可的资源补充自有样板。

## 使用

1. 视频工坊 → 世界引擎 → 选择“城镇集市 · 完整布景”或“喷泉庭院 · 完整布景”→ 新世界。新装默认选择城镇；已有工程不会被替换。
2. 城镇含 41 个布景对象、两名可摆姿态演员和三个机位书签；庭院为较小的对话布景。“添加内置布景”可搜索并添加 14 类道具，也能继续导入自备 GLB。
3. 自由视角中用“查看全景”框住场景；摄影机画面使用当前输出机位。保存机位方案后，可在多机位监看里对照。
4. 保存参考画面或应用到镜头参考，再生成关键帧与视频；预演画面只提供布景和构图，不保证最终模型保持所有细节。
5. 导出预演视频生成无声 WebM；桌面逐帧导出 MP4 使用真实 FFmpeg，支持固定帧率、尺寸、取消和重试编码。

内置布景标识随世界工程保存，导入另一台安装同版本 MoJing 的机器后使用软件自带资源；用户导入的模型仍按现有工程协议嵌入媒体。内置 GLB 含纹理，不依赖外部 CDN 或在线素材库。应用自身可能进行连通性检测，这与场景素材加载无关。

## 资源与画面边界

资源来自 [Kenney Fantasy Town Kit 2.0](https://kenney.nl/assets/fantasy-town-kit)，许可 CC0 1.0。原始许可与来源保存在 `public/world/town/`。`scripts/build-world-town-assets.mjs` 将原始模块组装为民居、商铺、塔楼等预制件，合并静态几何并嵌入配色纹理，可从原始资源包重建。

当前是有具体布景的低多边形城镇，不是写实古城、照片扫描场景或物理写实渲染器。照片级效果还需要足够细节的模型、PBR 材质、灯光与环境资源。单张背景图片适合远景或固定机位，无法提供绕拍、背面和正确的立体遮挡。

## 验证

`world-sets-ui-e2e` 用真实 WebGL 加载模型和内嵌纹理，检查道具添加／撤销、无效模型拒绝、工程往返与重载、深浅主题和三种窗口宽度；实际编码并解码有运镜的 1280×720 WebM，核对真实时长和画面差异。

`world-offline-desktop-e2e` 在发布程序内加载完整城镇，正常点击逐帧导出，核对两机位的 24 帧 H.264 MP4、文件落盘、画面差异、正常播放器和重载。此路径验证安装包内资源与真实 IPC，不替换模型或编码器。
