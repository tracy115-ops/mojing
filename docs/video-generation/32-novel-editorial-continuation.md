# 小说审读与续写验证（0.3.4）

本轮继续检查正文的阅读质量。0.3.3 的三章编辑稿作为固定输入，之前的人工修改不计入本轮模型表现。程序回归、真实模型输出和最终桌面阅读分别记录。

## 修复依据与行为

- 真实审稿曾因 `C40-C48` 连续引用、`C100` 对照本章 `C77` 而整份失败。现在审稿支持最多连续20段和本章内对照，保留原始段间空白；越界、倒序、混用来源仍拒绝。修订替换继续要求唯一的单段原文，不放宽修改锚点。
- 审稿曾把模型派生的文风公约当作逐句禁令，批评必要心理，并建议添加手势。现在写作与审稿都明确文风偏好服务于内容，审稿收到共同叙事原则；每条世界、人物和地点设定分开，便于核对具体依据。不会静默改写已保存的公约。
- 审稿需检查目标是否真正相斥、争论后是否发生行动、让步或代价，不能把口头表态当成已经完成的后果。合理暂缓仍然允许。
- 圣经或审稿保存后，同窗口编辑器与侧栏即时更新；跨窗口使用 storage 事件。报告同时核对正文和审读上下文，过期报告不再展示成当前评分。侧栏以具体意见和原文为主，移除总分圆环与分数趋势图。
- 自动修订候选单独审读和保存；只有新报告没有严重问题且来源未改变才可采用。不再因问题数量减少采用仍有严重问题的稿件；拒绝候选不会覆盖原稿审稿，正文保持待修订并暂停。
- 有正文的章节默认显示草稿。重载时若未选中有效章节，选择首个有正文的章节，避免已保存作品仍显示空编辑区。修订预览打开后改了正文或设定，采用时会重新读取依据并拒绝旧建议。
- 真实第四章对照显示快速写作会破坏刚建立的约定并过度推断。普通章节与自动分段正文因此启用推理，分别预留16384/12288输出预算；规划、写作和审读共享证据范围、替代解释、承诺后果及避免重复转述的要求。推理需要更多时间和token，仍须以正文检验，不能认为打开开关就保证好小说。

三章基线来自 [0.3.3 内容记录](31-novel-reading-quality.md)，包含之前明确记录的模型输出、取舍和人工编辑。新一轮审稿、修订建议及续写另存证据，不能把恢复的旧内容说成此次自动生成。

第二章首次新审稿已不再按旧公约批评必要心理，并使用本章多段原文指出“是否内部上报”没有收束。模型提出5处修改，正常预览中只采用第1处：方票务先盘库存，缺票立即报告，无缺票则暂缓并等警方调取。第二章由3141变为3174字符，只有这33字符的净增来自本轮采用的模型段落，未人工替写。其余4处因无依据的层级要求、扩大取证投入以及新增行程而拒绝；不能用它们算作质量提升。

审稿仍会提出错误意见。例如建议凭包内泥土断言它并非来自干处，或让已经交出包的林岚“别碰包”。第三章新审稿发现陈默知道检查习惯却缺少来源、询问便利店前的路程与寒暄过长；其事实记录仍有把“提出申请”写成“已经收到四点回复”的引文不充分问题。编号合法不证明解释和事实提取正确。第三章报告使用修改第二章前的上下文，修改后需按过期报告理解。

## 同一前文与意图的续写对照

第二轮恢复同样的三章正文（含本轮第二章已采用的单段修改），清除失败第四章及其报告，以同样142字符意图重新生成。普通正文实际请求启用推理并使用16384输出预算；大纲审读产生516字符的方案，正文为5042字符。该轮没有人工替写正文。

这一次不能得出“推理模式使整章质量更好”的结论。新稿没有再把“未看见包”直接当成排除携包的证据，也提供了可核对的上车站点和时间；但仍有更明显的硬伤：开篇十四点四十七分早于第三章最后的十五点十七分，安全科与调度室楼层不符，摄像头描述的覆盖范围和实际看到的身体部位相互冲突。储物格先说外盖始终关闭，再说拍不清开关，发给警察的消息又断言始终关闭；结尾还把尚未排除的运营途中放包机会收窄为收车后三分钟。老周先否认见人进入，随后突然抛出“进来一个”“是你今晚想找的”，没有交代转变和知情依据。长短信复述、重复雨中骑行继续占用篇幅。

审稿首轮指出了时间冲突和老周改口，却使用不存在的本章编号，并有超过20段的引用范围。程序拒绝这份结果并自动重试，原始失败仍保留；不能把不合法的引用改成成功报告，也不能把“原文确实存在”误当成事实解释可靠。它的部分意见仍偏向用包身干燥排除雨中携带，事实记录也会把看不清的储物格描述成始终关闭。

重试后的有效报告将初稿标为待修订，发现时间、老周改口、师徒约定及查看记录的问题；仍漏掉楼层、摄像头覆盖和储物格矛盾。其建议包括靠犹豫动作解释改口、靠信号不好错过电话制造后果，未照单采用。模型随后给出5处修订，在正常预览中只选第1、2处：将到站改为十五点四十七分，让魏值班员把有限的核对结果写进记录。新增给师傅的消息、把人影当野猫的说法、用抽烟停顿解释改口均拒绝。第四章最终5100字符，仍是待编辑草稿，不能用这两处局部收益掩盖整章问题。

采用后的真实再审返回待修订，进一步指出储物格矛盾、三分钟推断忽略林岚本人在场、老周线索缺少来源，未将局部修改后的正文当成已完成。它仍漏掉楼层和镜头覆盖，也提出“白色疤痕比喻不应出现”等依据不足的换词意见。再审发现的问题更多，不能解释为本轮两处修改让正文更坏，也不能用分数变化来判断文学质量；具体收益与剩余问题分别记录。
