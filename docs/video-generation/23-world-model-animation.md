# 世界引擎模型动作片段

更新：2026-11-16。补齐 GLB 内嵌动作只能整段循环、无法安排入场或调整节奏的问题。

## 操作

1. 在「视频工坊 → 世界引擎」导入含内嵌动画的 `.glb`，在左侧选择该模型。
2. 右侧「模型动画」选择动作。源片段起点／终点指定原动画中的秒数；时间线起点指定在世界中的开始时间。
3. 设置 0.1–4 倍速，选择循环片段，或播放一次并保持末帧。入场前始终保持所选片段首帧，模型可见性仍由对象的可见开关控制。
4. 底部增加模型动作条。循环片段延伸至当前预演末尾，单次动作显示到实际结束；点击动作条选中模型并跳到开始时间。
5. 正常播放、拖动时间线、保存参考画面、预演视频及分镜构图回流都使用相同动作采样。参数可以撤销／重做，随世界和画布工程保存、导出和导入。

「恢复完整动作」将当前动作恢复为从零开始、原速整段循环。切换动作或静止姿态也会清空上一动作的片段参数；静止姿态恢复 GLB 原始姿态。没有新增生成模型调用。

## 时间规则

源片段范围以 GLB 内真实动画时长为界，原素材不被剪写。单次播放时长为 `(终点 − 起点) / 倍速`。时间线起点不跟随场景时长修改自动缩放；它表示固定世界秒数，可在调整场景后重新安排。超过当前预演时长的开始时间会保留，当前时间线不显示该片段条。

动作使用连续世界时间，与多机位的镜头内部运镜时间分开。切镜不会重启动作；场景短于多机位总长时仍按同一规则继续循环或保持末帧。重复区间包含首帧、不包含末帧；精确到循环边界回到首帧。单次播放包含并保持指定终点。

渲染按绝对时间采样，每次清除上次到达末帧时的暂停状态，因此从动作结束后倒拖也能恢复正确姿态。模型对象自身的变换／走位关键帧继续作用于 GLB 外层，不改写其内嵌动作轨道。

旧工程没有动作参数时，仍使用原有从零开始、原速整段循环。工程导入校验开始时间 0–60 秒、源起点／终点 0–3600 秒、正向非空区间、倍速和播放方式；导入后再根据实际 GLB 时长限制采样，超出源范围会保持实际终点，可用恢复按钮清空配置。

## 验证与边界

- `test:world-model-animation` 覆盖延迟入场、片段边界、倍速、循环／保持、倒拖、旧工程兼容，以及世界／画布包的参数保留、资源 ID 隔离和非法配置拒绝。
- `test:world-model-animation-ui-e2e` 使用隔离 Chrome、真实 WebGL 和含两个动作的 GLB，验证界面参数实际改变模型位置，包含倒拖、静止姿态还原、切换动作、撤销重做、截图恢复、真实 1280×720 WebM 解码、工程导出和重启恢复，以及深浅主题和三种窗口宽度。
- 继续运行原世界多机位和视频工坊回归；浏览器拦截外部网络，不消耗真实模型额度。

每个模型目前只能选择一个内嵌动作和一个源区间。未实现多动作拼接／过渡、分层混合、骨骼重定向、IK、反向播放、音频同步或 Draco／KTX 解码器。固定时间逐帧 MP4 导出见 [25-world-frame-export.md](./25-world-frame-export.md)。真实第三方复杂骨骼素材仍需逐个验收；回归用例验证模型节点动画，不代表所有骨骼资产已测试。
