# 画笔蒙版、局部重绘与本地恢复

更新：2026-11-16。承接 [18-media-editing-and-shot-transfer.md](./18-media-editing-and-shot-transfer.md)，补齐参考图重绘后保护原图的处理链。

## 使用方式

素材库、图像结果或画布检查器中选择「编辑图片」，可用矩形或「画笔蒙版」标记修改范围。画笔支持大小调整、擦除、撤销／重做、清空、叠加／黑白预览和保存蒙版。边缘柔化只在已画范围内生效。最多 200 笔，每笔最多 2000 个采样点，图片上限为 32 百万像素。

蒙版按原图尺寸导出；预览缩放不改变其坐标。局部编辑保持原图画幅，旋转或切换编辑模式会清除旧选区，避免坐标错位。裁剪仍先保存新副本再继续编辑。原始素材不覆盖。

## 模型执行方式

| 模式 | 发送给模型 | 最终结果 |
| --- | --- | --- |
| Agnes 等支持至少两张参考图的模型 | 原图和红色区域引导图；不发送不存在的 `mask` 参数 | 保留模型候选，再按真实灰度蒙版本地合成 |
| Stable Diffusion WebUI | `/sdapi/v1/img2img`，一张 `init_images`、独立 `mask` 和 `denoising_strength` | 保留模型候选，并再次按蒙版合成以保护原图 |
| 未标记局部区域 | 原图与整图编辑指令 | 模型生成的完整图片 |

蒙版为不透明灰度 PNG，白色修改、黑色保留。提交前校验源图与蒙版尺寸一致、蒙版非空、灰度及透明度合法；错误蒙版不会请求模型。WebUI 使用 `mask_blur: 0`、`inpainting_mask_invert: 0`、`inpaint_full_res: false`，由编辑器统一处理边缘。

WebUI 的请求宽高按源图取最接近的 8 倍数且至少为 64，最终合成回到源图尺寸。候选不同尺寸时会重采样；蒙版值为 0 的区域精确复制解码后的原图 RGBA，半灰区域按预乘透明度混合。PNG 编码字节不承诺与原文件相同。模型候选在选区内的构图、内容和边缘衔接仍受模型能力影响。

只有实际实现 WebUI 蒙版协议的适配器能声明原生蒙版；对其他适配器填写能力覆盖也不会凭空启用它。默认只给 `stable-diffusion` 开启。既有 `flux`／`comfyui` 名称仍使用 WebUI 兼容适配器，须由真实兼容接口显式声明蒙版能力；**没有实现原生 ComfyUI workflow**。自定义合同对重绘强度的约束同样执行，不静默发送被拒绝的参数。

## 候选、凭证与失败恢复

模型成功后先将原始候选加入素材库，记录 `rawOutputAssetId`，然后执行本地合成。原始候选保存 Provider 请求／响应快照；合成结果独立保存源图、蒙版和候选指纹，不借用候选收据冒充模型原始输出。请求快照仅保存蒙版指纹，不保存蒙版 base64。

本地合成失败或任务中断后，任务页提供「仅重试本地合成」。刷新后候选与任务仍保留；该路径不经过 Provider Router，即使模型接口已禁用也可完成本地处理。若排队的本地恢复被取消，再次恢复也使用已保存候选。缺少源图、蒙版、引导图或候选时先恢复素材，不自动重新生成。

任务名称及详情显示用户修改要求，完整模型提示保留在执行数据中。任务详情和素材库区分「模型原始候选」与「蒙版合成结果」。已完成的蒙版任务通过「从原图重新编辑」重新选择区域；当前不恢复旧矢量笔画或自动填回旧指令。没有成功候选的任务才提供「重新请求模型」。

排队／运行期间，源图、蒙版、引导图和原候选都受素材回收保护。画布工程导出包含蒙版及输入媒体，导入同时校验并重新映射源图／蒙版 ID；缺少蒙版则拒绝整个工程。独立素材包中的合成结果只保留指纹来源，不包含可重跑的任务。

## 验证与边界

`test:image-mask` 检查选区外像素、透明边缘混合、WebUI 载荷与快照脱敏、原生能力限制、坏输入拒绝、工程引用隔离及素材保护。

`test:image-mask-ui-e2e` 在隔离 Chrome 中使用真实 Canvas 和模拟 Agnes／WebUI，拦截所有外网，覆盖鼠标画笔、擦除、撤销／重做、蒙版保存、柔化边界、源图像素保护、原生重绘强度、旋转清除、深浅主题和 1600／900／650 宽度；注入模型成功后的本地失败，再刷新、禁用模型接口并通过任务页恢复，断言模型请求次数不增加。继续检查任务详情、重新编辑、真实工程媒体导出及空蒙版在调用前失败。

没有调用真实生成模型、消耗用户模型额度或运行真实 SD WebUI 服务。协议与像素测试不能代替实际模型的画质 A/B 验收。多图层绘制、已有蒙版载入、矢量笔画恢复、对象移除专用模型和原生 ComfyUI 工作流仍未实现。
