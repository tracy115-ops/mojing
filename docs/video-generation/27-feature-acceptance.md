## 复现

需要 Windows x64、WebView2、Chrome、Node.js 24、Rust/MSVC、FFmpeg / FFprobe，以及项目依赖。

```powershell
npm.cmd run build:windows
npm.cmd run test:feature-e2e
# 仅复跑选中的用例
node scripts/run-feature-e2e.mjs --only=application-ui-e2e,application-desktop-e2e
```

统一报告写入 `artifacts/feature-e2e-<UTC时间>/report.json`，每组保留日志与截图。记录源代码提交和业务代码差异 SHA256；测试期间业务源码变化会使整批验收失败。应在测试结束后修改源码或文档，避免 Vite 刷新打断浏览器用例。

浏览器使用独立用户目录；桌面测试使用独立 WebView2 目录，不读取用户已有密钥和项目。发布版测试加载程序内置前端，不导入 `/src` 模块，不替换 Tauri IPC。三个桌面报告均记录程序 SHA256，打包时必须与安装包所用发布程序一致。

## 本轮修复

1. **音乐假成功**：旧版在 API 异常、非 2xx、空结果或轮询失败后，返回固定 Pixabay 歌曲并提示创作成功。现在抛出实际错误，不添加作品、不编造时长；未配置或禁用的接口不提交请求。只支持明确说明协议的 Suno 兼容代理，不把 SiliconFlow／Udio 当作同协议接口使用。
2. **音乐误导反馈**：去除“免费无限次／固定扣一次额度”等没有实际计费依据的文案；固定歌词明确标为本地示例；去除没有实际处理的“音轨分离成功”按钮。新装作品列表为空；恢复时过滤系统内置的 `demo_track_1`，保留其他历史记录。旧版错误生成的其他记录不自动删除，用户需要自行核对。
3. **小说输入丢失**：旧版受控文本框仅在 1.5 秒后更新值，连续输入立即被旧值覆盖；换章／离开页面还可能取消尚未保存的文字。现在立即更新编辑草稿、合并延迟保存，失焦、换章、退出编辑器和页面离开时保存到原章节。章节独立挂载，防止草稿和生成中的显示内容串章。
4. **普通表单校验异常**：小说创建、漫画创建和新增音乐接口的必填校验留在表单内处理，不再产生未处理 Promise 异常。
5. **音乐布局与播放状态**：窄窗口改为单列、深浅主题使用项目变量；播放状态随真实音频事件更新，重载时不恢复虚假的“正在播放”。
6. **预演空文件与静止片头**：实测发现 MediaRecorder 的原生编码器可在短镜头结束后才完成初始化，导致空视频；只等待 start 事件又可能把等待时间写入片头。预演现在用 WebCodecs VP8 和 Mediabunny，按场景时间逐帧编码并写入帧时长，限制待编码队列。初始化与机器负载只影响等待时间，不跳过计划帧；失败／离开后释放编码器、恢复监看。回归覆盖编码失败、延迟初始化、实际时长和像素变化。需 Chromium / WebView2 的 WebCodecs；桌面另提供固定帧 H.264 MP4。
7. **规划失败与恢复**：切片、分镜、实体提取失败后标记实际失败步骤并清除运行状态；重试按输入指纹复用已完成步骤，修复成功后清除旧错误。即使旧 SceneSpec 仍在，修复分镜／提取也不重复切片；只有明确重新切片才重建全部规划。规划完成停在人工确认，确认前不生成付费资产。
8. **全局视觉设定丢失**：分镜与提取收到剧本全文，保留单镜切片之外的人物发型、衣服、场景和画面约束；提取请求显式携带字段 schema，防止缺少外观和场景的空规划进入资产链路。
9. **镜头说明被当成配音**：对白提取排除镜头编号、时间与制作标签；显式空对白、空旁白保持为空，TTS 不回退朗读镜头提示词。分镜保留衔接字段。
10. **模型输出截断**：规划输出额度提高到 8192 tokens，OpenAI 兼容接口明确拒绝 `finish_reason=length` 和空文本，不能把截断 JSON 自动补齐后当成成功。DeepSeek V4 的 JSON 请求使用官方 `thinking.type=disabled`，防止默认推理占完小额度的结构化输出；其他模型的请求保持原协议。依据：[DeepSeek Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode)。
11. **视觉验收方式**：文本模型不能做自动视觉质检时，预检给出具体模型原因；可明确选择人工逐镜验收，仍需审核并锁定候选，技术检查继续执行。自动模式仍校验视觉模型能力，生成过程中不能切换策略。
12. **配置与流程面板**：保存 LLM 的自定义图像输入能力；空项目的流程面板保持稳定引用，避免无限重渲染；桌面截图等待临时消息消失时移开鼠标，避免悬停暂停关闭计时。
13. **Agnes 生图种子越界**：真实服务拒绝应用派生的十亿级镜头种子，提示只接受 `-1～999`。现在能力契约声明实际范围，确定性基础种子／候选种子稳定映射到 `0～999`，保留 `-1` 随机语义；Router、直接适配器和请求快照使用同一映射。桌面回归的 HTTP fixture 也检查范围，防止再次接受真实服务会拒绝的参数。
14. **参考图冻结道具状态**：真实关键帧把人物参考图中的撑伞状态复制到“收拢雨伞”的镜头。旧提示词把参考图所有细节设为最高优先级，现在明确：身份与服装由主体参考决定，姿态、表情、取景以及可移动道具的位置和开合由首帧状态决定。实体提取也明确把可移动道具与临时状态放到道具／镜头中，只有明确换装才建立服装变体。
    真实复验中，仅修改英文优先级仍未解决撑伞；还需要在正常界面写明“伞布紧贴伞杆成细长束状、伞尖朝下、J 形柄、头顶空着”，Agnes 重生成才得到合拢伞。这是提示词改进的实际边界，不能承诺任意道具都会正确。
15. **修改关键帧后不能继续流程**：手动修改提示词／重生图片会清除旧阶段。总览原来错误地用“全部视频已通过”判断能否开始生成视频，现在使用“全部关键帧已通过”，可从 idle 正常继续配音和视频生产。发布版回归覆盖修改、重生、批准、显式继续的全过程。
16. **视频素材元数据不实**：真实 H3 文件为 1376×768、5.167 秒，但适配器给出预设 1280×720、5 秒。工作台现在优先读取已保存视频的实际尺寸和时长，保留原始服务快照；读取失败不触发重复付费生成。发布版回归故意让远端元数据与实际文件不符，核对本地结果。
17. **真实视频无法进入审片**：WebView2 对约 2.4 MB 的内联视频执行 `fetch(data URI)` 返回 `Failed to fetch`，小文件打桩未暴露。视频检查改为直接把 Base64 解码为 Blob，再计算完整文件指纹和解码首、中、尾帧；发布版回归用超过 2 MB 的有效 MP4 经真实 IPC 导入。
18. **默认场景过于简陋**：新增包含 41 个立体布景对象和两名演员的城镇集市、喷泉庭院，以及 14 类可重复添加的内置道具。资源来自 Kenney Fantasy Town Kit 2.0（CC0），组装为包含纹理的独立 GLB，随安装包离线提供。修复大场景自阴影条纹，新增查看全景；允许 GLB 内嵌纹理所需的本地 blob 连接。属于低多边形场景，不是照片级渲染或竞品截图的原始城市。见 [完整场景说明](./29-world-scene-sets.md)。
19. **小说真实生成截断／跑题**：创建向导请求显式 JSON、8192 tokens，角色和地点数组用对象字段返回；流式适配器与普通生成共享输出格式和 DeepSeek V4 thinking 规则，明确拒绝截断、空结果、异常 EOF，并释放 reader。章节编辑器继承项目题材，携带简介、文风、世界规则、人物、地点和总纲，避免悬疑默认写成玄幻。增加分块 UTF-8 SSE、截断等契约及实际界面请求上下文回归。
20. **漫画有脚本却不出图**：分镜脚本返回的 spec 原先丢失 panels，runner 又因新人物分支丢弃完整 spec，导致后续全部跳过；新人物编号在归一化时也被误删。现在完整传递 spec，先生成分镜和人物，再生成角色参考与逐格图片；重试不把部分出图当作全部完成，保留完整源主题。四格、九宫格、主格和长条的菜单值加入真实 Canvas 拼页，避免进入默认单槽后漏画。
21. **漫画对白超出椭圆／重排丢失原图**：真实四格出图后，发现文字按椭圆外接矩形排在顶部，部分字落到框外。现在按椭圆内接矩形换行、垂直居中，并随行数增大气泡；无法容纳的对白报告失败，不静默截断。逐格保留未烧录的原图，重复烧录不叠字，改字号可直接重排与拼页；历史作品缺少原图时先重建必要的分镜图，避免清空图片后直接跳过对白。
