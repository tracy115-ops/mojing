# 视频工坊：系列连续创作方案与实施清单

本文档定义视频工坊从“单次生成工具”演进为“系列短剧生产工作台”的目标流程，并记录当前代码中的实现状态、待优化项和上线前验证项。

最后更新：2026-08-14

## 1. 产品目标

用户先创建一个**系列**，再在系列中持续创建**剧集**。角色、场景、服装、音色和视觉风格属于系列资产；每一集继承这些资产，并承接上一集的剧情状态和视觉结尾。

目标不是让用户手动配置越来越多的步骤，而是在默认流程中自动保障：

1. 同一角色跨镜头、跨剧集使用一致的角色身份与参考图。
2. 每集开头能承接上一集的地点、人物状态和未解决事件。
3. 剧本、小说章节到分镜、关键帧、视频的过程可追踪、可审核、可从失败处重跑。
4. 新手只需要完成“系列设定 → 剧集剧本 → 审核关键帧 → 生成”；高级用户可展开查看并重跑具体阶段。

## 2. 目标工作流

```text
新建系列
  ├─ 配置系列资产：角色立绘 / 三视图 / 服装 / 音色 / 场景 / 视觉圣经
  └─ 新建剧集
       ├─ 输入来源：已有小说章节 或 粘贴本集剧本
       ├─ 剧本解析与切片（自动）
       ├─ 分镜规划
       ├─ 提取角色、场景、道具
       ├─ 绑定系列资产与上一集连续性
       ├─ 生成角色锚点、场景图、关键帧
       ├─ 人工/AI 审核关键帧
       └─ 生成视频、音频、合成、导出
```

### 2.1 角色与场景的绑定规则

- 系列项目的 `metadata.seriesCharacters` 和 `metadata.seriesScenes` 是唯一的全局资产来源。
- 剧本解析后，以角色**名称或别名**匹配系列角色；匹配成功后，分镜中的角色 ID 替换为系列角色 ID。
- 匹配后的角色沿用系列资产中的立绘、三视图、服装变体和音色；镜头可根据剧本文字自动匹配服装，也可在镜头面板手动指定。
- 场景同样按名称或别名替换为系列场景资产；系列视觉圣经会追加到本集画面风格上下文。
- 为避免修改全局资产后悄悄改写已完成剧集，剧集使用的是一次绑定后的快照。需要更新时，由用户显式执行“同步系列资产”，并从关键帧阶段重新生成。

### 2.2 剧集连续性规则

- 新建剧集时记录 `previousEpisodeId`。
- 上一集的 `episodeEndingSummary` 自动作为下一集的分镜上下文。
- 上一集最后一个有效关键帧会作为下一集的开场参考图。
- 系列剧集生成完关键帧后暂停在“等待审核”；确认后才进入耗时较高的视频生成。

## 4. 待优化（按优先级）

### P0：统一“粘贴剧本”和“小说章节”的前处理

当前存在一个流程不一致：

- 选择已有小说章节时，使用 `VideoPipeline`，会运行“章节切片 → 分镜规划 → 角色/场景提取”。
- 直接粘贴本集剧本时，当前使用快速多镜头解析，直接生成 `SceneSpec`，**不会运行章节切片链路**。

这会导致粘贴长剧本的剧集缺少稳定的节奏拆分、叙事边界和统一的角色首次出场信息。应改为：将粘贴剧本包装成一个临时剧本章节，进入与小说相同的 `VideoPipeline` 前处理；界面名称统一为“剧本解析与分镜规划”，不向新手暴露旧的技术步骤名。

验收标准：不论输入来自小说还是粘贴剧本，都会产出可查看的切片、分镜、提取结果，并在绑定系列资产后进入关键帧阶段。

### P1：系列资产匹配的确定性与可见性

当前按名称/别名匹配。需要补强：

- 在剧本解析完成后显示“已匹配 / 未匹配 / 新角色候选”列表。
- 未匹配角色不得静默生成新的同名立绘；应让用户选择“映射到已有角色”或“新增为系列角色”。
- 为角色增加稳定的显示名、别名和版本号，减少改名导致的匹配失败。
- 给每个镜头显示实际引用的角色、服装、场景和参考图来源。

### P1：连续性审核闭环

当前 AI 视觉审核和剧情审核会给出结果，但不阻止用户继续。建议增加可配置策略：

- 默认：有严重角色/场景冲突时要求人工确认后继续。
- 高级：允许用户关闭阻断，仅保留告警。
- 剧集结尾摘要应基于已确认的关键帧、旁白和剧本共同生成，而非仅凭分镜文本。

### P1：界面收口与命名

- 将流水线前 3 步在普通视图归为“剧本解析与分镜规划”，高级视图可展开“切片 / 分镜 / 提取”。
- 清理仍遗留在注释、文案或重跑逻辑中的 `Direct`/“直接生成”语义，避免用户误以为可以绕过系列一致性流程。
- 在系列工作台中将“角色资产库、视觉圣经、剧集”作为固定的三段主布局，让剧集入口更显眼。

### P2：模型设置继续简化

- 新手模式只显示：接口用途、接口地址、密钥、模型 ID、立即使用。
- 高级模式才显示默认模型、任务模型绑定和多模型切换。
- 添加接口成功后应显示实际生效的用途和模型，避免“已保存但不知道在何处使用”。

### P2：合成和失败诊断

- 对每个视频片段记录下载、解码、转码、合成的结果和失败原因。
- 合成失败时显示“有效片段数 / 无效片段数 / 每段原因 / 可重试入口”，而非只显示“没有有效 clip”。
- 为供应商返回空文件、HTML 错误页、无视频流等情况补充自动判别和单片重试。

## 5. 必须验证的场景

### 5.1 系列与资产

1. 新建系列后，角色立绘、三视图、服装、音色和场景能保存并在重启后保留。
2. 在剧本中使用角色名与别名时，分镜都绑定到同一系列角色 ID。
3. 修改系列角色立绘后，已完成剧集保持不变；点击“同步系列资产”后，仅该剧集从关键帧阶段重新生成。
4. 剧本中出现未匹配角色时，当前行为与设计预期一致，且不会覆盖既有角色资产。

### 5.2 连续剧集

1. 创建第 2 集时自动关联第 1 集，并带入第 1 集结尾摘要。
2. 第 2 集首镜能读取第 1 集最后有效关键帧作为参考图。
3. 第 1 集无有效关键帧或无结尾摘要时，系统应降级运行并明确提示缺失项。
4. 系列剧集在关键帧完成后必须进入“等待审核”；确认后才能启动视频生成。

### 5.3 两种剧本来源

1. 选择已有小说章节：确认章节切片、分镜、提取阶段依次完成。
2. 粘贴短剧本：当前需记录其绕过章节切片的现状；完成 P0 后应与小说路径一致。
3. 长剧本、多角色、多场景、跨地点剧情均需验证镜头数量、角色绑定和场景绑定。

### 5.4 视频与合成

1. 每个镜头有有效视频流时，能完成 re-encode 和成片合成。
2. 部分镜头失败时，能定位失败片段并单镜头重试。
3. 所有上游视频无效时，错误信息应包含供应商响应或媒体检测原因。
4. 不同视频供应商、横屏/竖屏/方形比例、不同镜头时长均需回归。

### 5.5 设置与发布

1. 添加文本、图像、视频、语音接口分别落入正确用途分类。
2. 非 Edge TTS 接口未填写模型 ID 时不能保存；Edge TTS 可无需模型、地址与密钥保存。
3. 保存接口后，勾选“立即使用”时该接口及模型确实成为当前用途的生效配置。
4. 中英文界面下新增文案均正常显示。
5. 执行 `npm run build` 与 Windows 安装包构建，并安装验证新视频工坊入口实际生效。

## 6. 相关实现位置

- `src/components/Video/VideoSeriesWorkspace.tsx`：系列资产库、剧集列表、连续性编辑和资产同步入口。
- `src/components/Video/VideoView.tsx`：视频工坊主入口、创建剧集、传递系列上下文。
- `src/components/Video/VideoGeneratorModal.tsx`：从小说章节选择素材并启动视频流水线。
- `src/services/video/pipeline.ts`：小说章节的切片、分镜、提取和后续流水线编排。
- `src/services/video/series-character-library.ts`：系列角色、场景、服装和风格绑定。
- `src/services/video/core/pipeline-runner.ts`：关键帧审核门槛、上一集关键帧开场参考、单步重跑。
- `src/components/Settings/ProviderSettings.tsx`：接口、模型 ID 和即时生效配置。

## 7. 推荐实施顺序

1. 完成 P0：让粘贴剧本进入统一的切片/分镜/提取链路。
2. 完成 P1 资产匹配可视化和未匹配角色处理，再增强连续性审核阻断策略。
3. 完成 P1 界面命名收口，隐藏技术细节但保留高级检查与重跑。
4. 完成 P2 的设置引导和合成失败诊断。
5. 按第 5 节进行完整回归，并使用真实供应商接口完成至少一部两集连续短剧验收。
