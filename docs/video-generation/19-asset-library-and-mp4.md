# 素材整理与 MP4 副本

素材库保留已有的项目素材预览、生成复用、画布、图像编辑和分镜回流，补充本地目录和批量管理。

## 使用方式

- 左侧切换全部、未归档、项目素材、回收站及文件夹。文件夹可建立父子层级，父目录会显示其子目录的素材。移除文件夹只把素材和子目录上移，不删除媒体。
- 勾选素材后「整理素材」，批量移动、设置业务分类、添加或移除标签。单项整理还可改名。名称、内容及标签可搜索，也可单独按媒体类型、业务分类和标签筛选。
- 项目素材由原项目管理；可以预览、复用或复制到创作素材库，再独立整理。回收创作库副本不会删除项目产物。
- 「移入回收站」隐藏素材并保留恢复记录。画布节点及参数、世界模型、电商参考、草稿、排队和运行任务使用中的素材受到 Store 层保护；批量操作只回收未引用的项，并显示保留数量。已完成或失败任务不单独阻止回收。
- 回收站不提供生成复用；缺失或回收中的参考在提交生成任务之前拒绝。恢复保留原 ID、目录、标签和原始媒体；原目录已不存在时回到未归档。
- 「清除记录」只移除回收站记录，不删除磁盘文件，不宣称释放磁盘空间。文件清理继续由现有项目资产管理承担。

文件夹、标签、回收记录和媒体沿用 IndexedDB 工作区保存。旧工作区自动使用空文件夹和空回收站，现有素材保持可用。

## 素材包

勾选素材后「导出素材包」，下载 `.assets.json`，包含媒体 Data URI、文本、标签、业务分类和所需的目录及祖先目录。远端媒体下载失败时拒绝导出，不用失效链接冒充可携带的副本。每包限制 200 项、256 MB。

导入先检查整个包、目录关系、防环、媒体嵌入、素材类型、标签及目录引用，再一次写入状态。素材和目录全部分配新 ID，并置于新的导入目录；不会覆盖当前画布引用或同名素材。不从包中恢复运行任务。画布／世界工程导入保留标签，但不会沿用另一个素材库的目录 ID。

这是一份包含原始媒体的 JSON 包，尚无 ZIP 压缩、增量同步或云端共享服务。

## 另存 MP4 副本

视频卡片的「另存 MP4 副本」使用桌面 FFmpeg，接受本地、Data URI 或可下载的远程视频，保存新的 H.264／AAC／YUV420P MP4。只保留首个视频流和可选的首个音轨，启用 faststart；静音原片可正常转换。可保留原尺寸或限制高度为 720／1080，兼容转换会取偶数尺寸且不放大原片。转换完成后探测可播放画面，再加入素材库，原片和已审核的分镜保持独立。

原有无损导出继续使用既有路径；新增的 `compatibleMp4` 显式要求重新编码。后端拒绝原片与输出路径相同的请求，防止覆盖原片。

浏览器显示桌面要求，不提供假的转码成功。MP4 转码不会提升原片画质，也不会自动满足模型的全部时长、大小、画幅等限制。转换后的文件没有沿用旧公网 URL；现可在 [S3 兼容上传](./22-media-upload.md) 窗口转换并自动选中新副本，再上传为模型可读链接。Ark 私有素材上传及授权仍未实现。

## 验证入口

- `npm run test:studio-library`：目录、防环、全部引用槽、混合批次回收、恢复、素材包层级重映射和原子校验。
- `npm run test:studio-library-ui-e2e`：真实 Chrome 操作文件夹、批量移动／分类／标签、包导入导出、回收恢复、移除目录、项目复制、桌面功能门槛、持久化和深浅主题／窄屏布局；外网拦截，不调用生成模型。
- `cargo test --manifest-path src-tauri/Cargo.toml --lib compatible_mp4_tests -- --nocapture`：真实 FFmpeg 将 VP8／Opus 转为 H.264／AAC，检查尺寸不放大、静音转换、原片完整及同路径拒绝；需要本机 FFmpeg 和 ffprobe。
- `npm run build`、`test:studio`、已有创作空间与分镜工作流回归。
