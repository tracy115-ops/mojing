# 世界引擎多机位同步监看

更新：2026-11-16。补齐切换机位后无法同时比较构图的问题。

## 操作

1. 在「视频工坊 → 世界引擎」摆场，并保存几个机位方案，或建立多机位序列。
2. 在视口上方选择「多机位监看」，再选双画面或四画面。每格可选当前输出、主摄影机、机位方案或序列镜头，也可清空。窄视口的双画面上下排列。
3. 播放或拖动原时间线，比较同一时刻的演员走位和不同机位的画面。每格标出焦距与世界时间；序列机位另显示待切入／镜头内／已结束及镜头内部时间。
4. 「保存画面」将该格的机位构图保存为独立参考图，进入现有素材库，可继续用于画布或分镜。
5. 「采用机位」复制该来源的完整摄影机和运镜曲线到当前序列镜头；未启用序列时应用到主摄影机。曲线按目标镜头时长缩放，之后可在右侧编辑，支持撤销／重做。

当前输出随启用的序列切镜，主摄影机始终表示场景的原主机位。机位方案和其他镜头保存独立快照，采用时不会改写来源或其他镜头。查看、选格、切换布局和截图本身不修改场景。

监看布局和格子选择是临时视图状态，不作为场景数据或工程格式保存；重新打开默认显示当前输出及已有的前几个机位。切换世界重新匹配来源，已删除的来源显示为空格；不会悄悄改成另一台摄影机。

## 时间、画幅与输出

所有格子使用同一个世界时间、同一批场景对象和 GLB 动作状态。摄影机主视角与书签使用场景时间；序列镜头按自身在序列中的开始时间计算局部运镜，区间外保持相机首／末位置。即使某机位尚未切入，演员仍显示当前世界时刻的姿态。该状态不代表提前重播演员动作。

监看采用一个 WebGL renderer，在不同视口中绘制同一场景；没有为每格创建新场景、重载 GLB 或增加独立播放计时。画面保持世界画幅并留黑边，支持材质、白模和线性深度。四画面会增加绘制工作量，复杂场景可切到双画面或单摄影机视图。本轮未做跨设备帧率基准或桌面显卡性能验收。

每格参考图仍以长边 1280 保存 PNG，横屏为 1280×720，9:16 为 720×1280。截图完成后恢复原时间、当前输出摄影机、监看布局及渲染状态。

「保存参考画面」「送入画布」「应用为镜头参考」及预演视频继续使用当前输出。录像期间临时显示当前输出单画面，结束或失败后恢复监看；监看格子的 UI 与拼屏不写入成片。原录像使用浏览器 MediaRecorder WebM；桌面另有固定时间逐帧 MP4，见 [25-world-frame-export.md](./25-world-frame-export.md)。未实现多路独立录像、拼屏导出或在线协作。
