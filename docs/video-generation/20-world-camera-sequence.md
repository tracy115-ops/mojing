# 世界引擎多机位序列

世界引擎在已有机位书签、相机关键帧和运镜上增加可编辑的切镜序列，连接场景预演与项目分镜制作。

## 操作

1. 在世界中摆放演员、道具和走位，设置主摄影机，或先保存多个机位方案。
2. 在视口下方「多机位序列」选择主摄影机或书签，再「加入序列」。每个镜头保存独立的相机快照，后续编辑不会改写源书签或其他镜头。
3. 设置镜头名称、时长和运镜，前移／后移、复制或删除。点击镜头序号进入该镜头的摄影机画面；右侧位置、目标、焦距、关键帧、机位对齐和轨迹绘制编辑当前序列镜头。
4. 播放、保存参考画面或导出预演视频，均按相同的切镜与焦距计算。关闭「使用多机位」可以继续使用原主摄影机；序列内容保留。
5. 「批量回流分镜」自动展示各镜头中间时刻的构图，选择项目并逐项分配不同的目标分镜。默认依次对应项目已有镜头，可重新指定。确认后一次写入全部参考图，并在素材库保存这些构图。

最多 24 个镜头，总长不超过 60 秒，单镜头至少 0.25 秒。当前只支持直接切镜，没有淡化或叠化。

## 时间与输出

- 启用序列时，播放和录像时长等于各序列镜头时长之和；关闭时使用原场景动画时长。
- 相机关键帧使用镜头内部时间。加入书签或修改镜头时长会按比例调整其相机关键帧。
- 演员、对象和 GLB 动画使用连续的世界时间，切镜不从零重播。位置曲线在最后关键帧后保持末位置；走跑等循环动作和 GLB 内嵌循环动画继续。
- 「场景动画时长」用于已有对象／主摄影机／书签关键帧的整体缩放，不会隐式改变已编排镜头的长度。序列短于动画时只播放对应时间范围，长于动画时按上述规则延续。
- 切镜边界采用前段不含结尾、后段包含开头的规则，恰好到达切点时显示新机位。预览、PNG 和 WebM 均调用同一求值函数，包含镜头焦距。
- 批量截图会恢复原播放头与视口。原预演录像沿用浏览器 MediaRecorder、长边 1280 的真实 WebM 输出；桌面增加独立的固定时间逐帧 MP4，见 [25-world-frame-export.md](./25-world-frame-export.md)。两种输出均为场景预演画面。

## 分镜回流与一致性

回流写入 `previsReferenceImage`、`previsWorldId`，替换目标分镜的手工参考，并将衔接设为切镜。项目原有文字、镜头时长和角色身份绑定保留。序列中的 3D 演员只表达站位与构图，不替代真实角色参考图。

Store 在一次状态更新中完成全部映射和产物失效：相关旧关键帧、选中／锁定版本、当前视频和已有成片失效，受影响制作阶段重置。历史候选仍可查看，其他镜头的当前产物保留。后续生成与人工审片继续使用原有质量流程，预演图不会成为已审核视频。

预览打开时保存世界快照；选择项目时保存分镜快照。保存媒体后、写入分镜前再次核对，场景或分镜变化、目标缺失／重复、制作阶段正在运行时拒绝整个批次，避免部分更新或覆盖新编辑。参考图不是自动持续同步的链接；改动世界后需要重新检查并应用。

序列支持工作区持久化、撤销／重做，以及包含 GLB 和其他引用媒体的世界／画布工程导入导出。导入校验镜头数、总时长、标识、每段相机、局部关键帧和焦距；旧工程没有序列时沿用主摄影机。

## 验证

- `npm run test:world-sequence`：切点、局部运镜时间、焦距、连续走位、快照隔离、旧文档兼容与工程导入校验。
- `npm run test:world-sequence-ui-e2e`：隔离 Chrome、真实 WebGL，操作机位来源、时长、运镜、顺序、复制、删除、撤销和摄影机检查器；真实录制并解码 1280×720 视频，验证切镜；预览、调整分镜映射、过期／运行状态拒绝、原子回流和产物失效；重启恢复、深浅主题及 1600／900／650px 布局。
- `npm run build`、`test:studio`、`test:derived-artifacts`、`test:studio-ui-e2e` 与 `test:video-ui-e2e`：继续验证原世界与制作链。

浏览器回归拦截外部网络，没有调用真实生成模型或消耗模型额度。本轮没有进行生成画质 A/B 评测。

GLB 动作区间、倍速、延迟入场与循环／保持见 [23-world-model-animation.md](./23-world-model-animation.md)。原生蒙版修复与 S3 兼容上传分别见 21、22 号文档。
双／四画面同步监看、单机位参考图与机位曲线采用见 [24-world-camera-monitor.md](./24-world-camera-monitor.md)。
逐帧编码、原生核对与编码失败重试见 [25-world-frame-export.md](./25-world-frame-export.md)。仍需补齐复杂缓动、骨骼动作分层与 IK；方舟私有资产注册、可执行技能／插件运行时和云协作仍见逐页差异清单。小云雀仍需真实开放 API 与账号配置。
